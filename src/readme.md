# MoDrive - STM32G4 电机驱动项目

## 项目概述

MoDrive 是一个基于 STM32G473RCTx 微控制器的完整 FOC（场定向控制）电机驱动解决方案。项目采用模块化设计，包含硬件抽象层、电机控制算法库、状态机管理和参数配置系统。

### 核心特性
- **硬件平台**：STM32G473RCTx (Cortex-M4, 170MHz)
- **控制算法**：FOC（场定向控制）算法
- **编码器支持**：绝对值式编码器
- **控制频率**：电流环 20kHz，速度环 1kHz
- **通信接口**：支持调试和数据监控
- **校准功能**：完整的编码器和电流采样校准流程

## 校准流程

### 1. 自动校准
1. 系统上电后自动进入校准状态
2. 执行电流采样偏移校准
3. 执行编码器零点和极对数校准
4. 校准完成后自动进入空闲状态

### 2. 校准阶段
- **电流校准**：采样三路相电流偏移
- **对齐阶段**：对齐到0°电角度
- **旋转阶段**：开环旋转检测极对数
- **偏移计算**：计算编码器零点偏移

## 调试与监控

### 1. JScope 监控
项目包含 JScope 配置文件（`Debug_Jscop.jscope`），可监控：
- 电角度、速度
- d/q轴电流
- 目标位置/速度
- PID 输出

### 2. 串口调试
通过 `it.c` 中的指令接口进行调试：
- 设置目标位置/速度
- 调整 PID 参数
- 读取状态信息

## 已知问题

1. **编码器校准**：当前使用单点采样，建议优化为多点线性回归
2. **参数存储**：校准参数尚未保存到 Flash
3. **错误处理**：部分错误处理机制需要完善
4. **实时性**：在高负载下需要进一步优化性能

## motorlib 架构层面改进分析

| 优先级 | 问题 | 影响 | 改进方向 |
|--------|------|------|----------|
| 🔴 高 | 状态机调度跑在 10kHz 中断上下文 | 实时性、安全、并发 | 将 `sm_dispatch` 移到主循环，ISR 仅设置标志 |
| 🔴 高 | 保护触发后无 FAULT 状态 | 安全状态不一致 | 增加 `MOTOR_STATUS_FAULT`，故障时切换状态 |
| 🟡 中 | `motor_1` 全局指针直接暴露 | 多电机扩展、封装 | 移除 `extern`，改用工厂函数或上层持有 |
| 🟡 中 | 目标值使用裸指针 (`target_pos` 等) | 数据竞态、语义不一致 | 改为值拷贝接口 `motor_set_target_xxx()` |
| 🟡 中 | `_motorlib_internal.h` 过度包含 | 编译耦合、构建效率 | 用前向声明替代完整头文件包含 |
| 🟢 低 | 调试变量静态污染 | 代码整洁、RAM 占用 | 统一 `motor_debug.h` 或放入实例结构体 |
| 🟢 低 | `M_PI` / `RAD_TO_DEG` 重复定义 | 命名空间污染 | 统一为项目内部前缀常量 |
| 🟢 低 | `motor_interface_flag.h` 职责不单一 | 可维护性 | 拆分为 flag / mode 两个头文件 |

> 注：以上问题主要从架构层面分析，部分小功能暂时屏蔽或未实现，但均已留有接口。
