# CiA 402 从站开发计划

## 1. 当前状态评估

### 1.1 已具备的基础能力

| 模块 | 状态 | 说明 |
|------|------|------|
| CANopenNode V4 协议栈 | ✅ 已集成 | 支持301/303/304/305标准 |
| STM32 FDCAN 驱动 | ✅ 已实现 | 基于HAL库，支持中断收发 |
| 心跳与SDO通信 | ✅ 已验证 | 可通过SDO读写对象字典参数 |
| PDO 基础框架 | ✅ 已配置 | TPDO1已映射0x606C速度值 |
| FOC电机控制 | ✅ 已运行 | 电流环20kHz，速度环1kHz |
| 状态机框架 | ✅ 已存在 | motorlib状态机支持校准/运行/空闲状态 |

### 1.2 已验证的功能

- **心跳通信**：节点ID 21，心跳周期1000ms，主站可正常监控
- **SDO参数修改**：可通过SDO修改心跳周期等通信参数
- **速度数据上报**：TPDO1周期性发送实际速度值（0x606C）
- **电机闭环控制**：速度环、电流环正常运行

### 1.3 缺失的核心组件

| 组件 | 缺失内容 | 影响 |
|------|----------|------|
| 对象字典 | 缺少6040h控制字、6041h状态字、6060h模式控制等CiA 402核心对象 | 无法接收控制命令 |
| PDS状态机 | 无CiA 402电源驱动状态机实现 | 无法按标准流程启停电机 |
| 控制模式处理 | 无PP/PV/CSP/CSV等模式逻辑 | 无法执行主站下发的运动指令 |
| 错误管理 | 无603Fh错误码映射机制 | 故障无法标准化上报 |

### 1.4 技术债务与限制

- **OD文件**：当前为手动维护，添加CiA 402对象后需改用CANopenEditor管理
- **PDO映射**：TPDO1已固定映射速度值，需重新设计PDO映射方案
- **周期同步**：当前速度环1kHz，需评估是否满足CSV/CSP模式的同步要求

## 2. 开发阶段规划

### 阶段一：对象字典扩展

#### 2.1.1 新增对象清单

必须添加的CiA 402核心对象：

| 索引 | 名称 | 类型 | 访问 | PDO映射 |
|------|------|------|------|---------|
| 0x6040 | Controlword | UINT16 | RW | RPDO |
| 0x6041 | Statusword | UINT16 | RO | TPDO |
| 0x6060 | Modes of Operation | INT8 | RW | RPDO |
| 0x6061 | Modes of Operation Display | INT8 | RO | TPDO |
| 0x603F | Error Code | UINT16 | RO | TPDO |
| 0x6064 | Position Actual Value | INT32 | RO | TPDO |
| 0x606C | Velocity Actual Value | INT32 | RO | TPDO（已存在）|
| 0x6077 | Torque Actual Value | INT16 | RO | TPDO |
| 0x607A | Target Position | INT32 | RW | RPDO |
| 0x60FF | Target Velocity | INT32 | RW | RPDO |
| 0x60B2 | Torque Offset | INT16 | RW | RPDO |
| 0x6502 | Supported Drive Modes | UINT32 | RO | 无 |

#### 2.1.2 OD文件结构变更

- 使用CANopenEditor工具创建新的XDD/EDS文件
- 保留现有通信参数对象（1000h-1A03h）
- 在原有OD基础上新增402对象段

#### 2.1.3 PDO映射设计

**RPDO映射（主站→从站）：**

| RPDO | 映射对象 | 用途 |
|------|----------|------|
| RPDO1 | 0x6040（控制字）+ 0x6060（模式）| 命令与模式 |
| RPDO2 | 0x60FF（目标速度）| CSV/PV模式目标值 |
| RPDO3 | 0x607A（目标位置）| CSP/PP模式目标值 |
| RPDO4 | 0x60B2（目标转矩）| CST/TQ模式目标值 |

**TPDO映射（从站→主站）：**

| TPDO | 映射对象 | 用途 |
|------|----------|------|
| TPDO1 | 0x6041（状态字）| 状态反馈 |
| TPDO2 | 0x606C（实际速度）+ 0x6064（实际位置）| 反馈值 |
| TPDO3 | 0x603F（错误码）+ 0x6077（实际转矩）| 故障与转矩 |

#### 2.1.4 验证方法

- 使用主站SDO读取新增对象默认值
- 验证PDO映射配置可读写
- 确认TPDO按配置周期发送
