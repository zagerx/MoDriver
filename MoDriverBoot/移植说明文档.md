# OpenBLT 移植到 STM32G473RC 说明文档

## 1. 项目概述

本文档记录将 OpenBLT Bootloader 从官方 `ARMCM4_STM32G4_Nucleo_G474RE_GCC` Demo 工程移植到自定义 **STM32G473RC** 开发板的完整过程。

### 核心硬件差异
| 项目 | Nucleo-G474RE | 自定义板 (STM32G473RC) |
|------|---------------|------------------------|
| Flash 容量 | 512KB | **256KB** |
| 外部晶振 | 24MHz HSE | **无外部晶振，使用内部 HSI 16MHz** |
| LED | PA5 | **PC15** |
| CAN | PB8/PB9 (FDCAN1) | **PB5/PB6 (FDCAN2)** |
| 按键 | PC13 | **无** |
| 升级触发 | XCP CONNECT 轮询 | **CANopen NMT 指令 + RAM Magic Key** |

## 3. 编译环境准备

### 3.1 ARM GCC 交叉编译器
- 使用 `gcc-arm-none-eabi-10.3-2021.10`（Ubuntu 环境下）
- **注意**：当前 Demo 工程链接脚本使用了 GCC11+ 才支持的 `(READONLY)` 关键字，GCC10 编译会链接报错，需要手动删除（见下文）

### 3.2 Linux 上位机编译依赖
```bash
sudo apt update
sudo apt install cmake build-essential libusb-1.0-0-dev
```

### 3.3 编译 BootCommander
```bash
cd Host/Source/LibOpenBLT
mkdir -p build && cd build
cmake ..
make -j$(nproc)

cd ../../BootCommander
mkdir -p build && cd build
cmake ..
make -j$(nproc)

# 运行（注意大小写）
cd ../../../Host
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:.
./BootCommander --help
```

## 4. Bootloader 移植步骤

### 4.1 复制参考工程
```bash
cd Target/Demo
cp -r ARMCM4_STM32G4_Nucleo_G474RE_GCC  MoDriverBoot
cd MoDriverBoot
```

### 4.2 修改 Boot 目录

#### 1) 重命名链接脚本并同步 Makefile
```bash
cd Boot
mv STM32G474RETx_FLASH.ld STM32G473RCTx_FLASH.ld
```

修改 `makefile`：
```makefile
PROJ_NAME=openblt_stm32g473
CFLAGS += -DSTM32G473xx
LFLAGS += -T"STM32G473RCTx_FLASH.ld" -Wl,-Map=$(BIN_PATH)/$(PROJ_NAME).map
```

#### 2) 修复 GCC10 兼容性（关键）
打开 `STM32G473RCTx_FLASH.ld`，删除所有 5 处 `(READONLY)` 关键字：
- `.ARM.extab`
- `.ARM`
- `.preinit_array`
- `.init_array`
- `.fini_array`

修改前：`.ARM.extab (READONLY) :`
修改后：`.ARM.extab :`

#### 3) 核心配置 `blt_conf.h`
```c
/* 系统时钟 */
#define BOOT_CPU_XTAL_SPEED_KHZ          (16000)   /* HSI = 16MHz */
#define BOOT_CPU_SYSTEM_SPEED_KHZ        (160000)  /* 目标主频 160MHz */

/* Flash 容量 */
#define BOOT_NVM_SIZE_KB                 (256)     /* G473RC = 256KB */

/* 通信接口 */
#define BOOT_COM_CAN_ENABLE              (1)
#define BOOT_COM_CAN_BAUDRATE            (500000)
#define BOOT_COM_CAN_TX_MSG_ID           (0x7E1)
#define BOOT_COM_CAN_RX_MSG_ID           (0x667)
#define BOOT_COM_CAN_CHANNEL_INDEX       (1)       /* FDCAN2 !!! */
#define BOOT_COM_RS232_ENABLE            (0)       /* 不使用 UART */

/* 后门入口 */
#define BOOT_BACKDOOR_HOOKS_ENABLE       (1)       /* 启用 RAM Magic Key */
#define BOOT_CPU_USER_PROGRAM_START_HOOK (1)
#define BOOT_COP_HOOKS_ENABLE            (1)
```

#### 4) 时钟配置 `main.c`
由于没有外部晶振，需使用 **HSI + PLL**。

**关键修改点**：
- `LL_RCC_HSE_Enable()` → `LL_RCC_HSI_Enable()`
- PLL 源：`LL_RCC_PLLSOURCE_HSI`
- PLL 系数：M=DIV4, N=80, R=DIV2 → `16MHz/4*80/2 = 160MHz`
- FDCAN 时钟源：`LL_RCC_FDCAN_CLKSOURCE_PCLK1`

**完整代码参考**（已验证）：
```c
static void SystemClock_Config(void)
{
    LL_FLASH_SetLatency(LL_FLASH_LATENCY_4);
    while(LL_FLASH_GetLatency() != LL_FLASH_LATENCY_4);

    LL_PWR_EnableRange1BoostMode();
    LL_RCC_HSI_Enable();
    while(LL_RCC_HSI_IsReady() != 1);

    LL_RCC_PLL_ConfigDomain_SYS(LL_RCC_PLLSOURCE_HSI, LL_RCC_PLLM_DIV_4, 80, LL_RCC_PLLR_DIV_2);
    LL_RCC_PLL_EnableDomain_SYS();
    LL_RCC_PLL_Enable();
    while(LL_RCC_PLL_IsReady() != 1);

    LL_RCC_SetSysClkSource(LL_RCC_SYS_CLKSOURCE_PLL);
    LL_RCC_SetAHBPrescaler(LL_RCC_SYSCLK_DIV_2);
    while(LL_RCC_GetSysClkSource() != LL_RCC_SYS_CLKSOURCE_STATUS_PLL);

    /* 1us 过渡 */
    CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk;
    DWT->CTRL |= DWT_CTRL_CYCCNTENA_Msk;
    DWT->CYCCNT = 0;
    while(DWT->CYCCNT < 100);

    LL_RCC_SetAHBPrescaler(LL_RCC_SYSCLK_DIV_1);
    LL_RCC_SetAPB1Prescaler(LL_RCC_APB1_DIV_1);
    LL_RCC_SetAPB2Prescaler(LL_RCC_APB2_DIV_1);

    LL_SetSystemCoreClock(BOOT_CPU_SYSTEM_SPEED_KHZ * 1000u);
    if (HAL_InitTick(TICK_INT_PRIORITY) != HAL_OK)
    {
        ASSERT_RT(BLT_FALSE);
    }

    LL_RCC_SetFDCANClockSource(LL_RCC_FDCAN_CLKSOURCE_PCLK1);
}
```

#### 5) GPIO 初始化 `main.c`
注意 PC15 默认是 LSE 晶振引脚，必须先关闭 LSE：

```c
void HAL_MspInit(void)
{
    LL_GPIO_InitTypeDef GPIO_InitStruct;

    LL_APB2_GRP1_EnableClock(LL_APB2_GRP1_PERIPH_SYSCFG);
    LL_APB1_GRP1_EnableClock(LL_APB1_GRP1_PERIPH_PWR);
    LL_PWR_DisableUCPDDeadBattery();

    /* 关键：释放 PC15 为普通 GPIO */
    LL_RCC_LSE_Disable();

    /* 开 GPIO 时钟 */
    LL_AHB2_GRP1_EnableClock(LL_AHB2_GRP1_PERIPH_GPIOA);
    LL_AHB2_GRP1_EnableClock(LL_AHB2_GRP1_PERIPH_GPIOB);
    LL_AHB2_GRP1_EnableClock(LL_AHB2_GRP1_PERIPH_GPIOC);

    /* FDCAN2 时钟 */
    LL_APB1_GRP1_EnableClock(LL_APB1_GRP1_PERIPH_FDCAN);

    /* LED: PC15 */
    GPIO_InitStruct.Pin = LL_GPIO_PIN_15;
    GPIO_InitStruct.Mode = LL_GPIO_MODE_OUTPUT;
    GPIO_InitStruct.Speed = LL_GPIO_SPEED_FREQ_LOW;
    GPIO_InitStruct.OutputType = LL_GPIO_OUTPUT_PUSHPULL;
    GPIO_InitStruct.Pull = LL_GPIO_PULL_NO;
    LL_GPIO_Init(GPIOC, &GPIO_InitStruct);
    LL_GPIO_ResetOutputPin(GPIOC, LL_GPIO_PIN_15);

    /* CAN: PB5/PB6, AF9 (FDCAN2) */
    GPIO_InitStruct.Pin = LL_GPIO_PIN_5 | LL_GPIO_PIN_6;
    GPIO_InitStruct.Mode = LL_GPIO_MODE_ALTERNATE;
    GPIO_InitStruct.Speed = LL_GPIO_SPEED_FREQ_VERY_HIGH;
    GPIO_InitStruct.OutputType = LL_GPIO_OUTPUT_PUSHPULL;
    GPIO_InitStruct.Pull = LL_GPIO_PULL_NO;
    GPIO_InitStruct.Alternate = LL_GPIO_AF_9;
    LL_GPIO_Init(GPIOB, &GPIO_InitStruct);
}
```

#### 6) LED 驱动 `led.c`
将 `led.c` 中所有 `GPIOA/LL_GPIO_PIN_5` 改为 `GPIOC/LL_GPIO_PIN_15`：
- `LedBlinkTask()` 中的 `SetOutputPin` / `ResetOutputPin`
- `LedBlinkExit()` 中的 `ResetOutputPin`

#### 7) 后门逻辑 `hooks.c`
通过 **RAM Magic Key** 实现 APP 控制是否进入 Bootloader：

```c
#define BOOTLOADER_MAGIC_KEY  0xDEADBEEF
volatile uint32_t *bootFlag = (volatile uint32_t *)0x2000FFF0;

blt_bool BackDoorEntryHook(void)
{
    if (*bootFlag == BOOTLOADER_MAGIC_KEY)
    {
        *bootFlag = 0;  /* 清除标志，防止下次上电还生效 */
        return BLT_TRUE; /* 留在 Bootloader */
    }
    return BLT_FALSE; /* 直接跳 APP */
}
```

同时移除不存在的 PC13 按键检测逻辑。

## 5. APP 适配步骤

### 5.1 启动文件加 checksum 占位符
在 APP 的 `startup_stm32g4xxx.s` **向量表末尾**添加：
```asm
.word 0x55AA11EE   /* Reserved for OpenBLT checksum */
```

### 5.2 链接脚本修改
- Flash 起始地址：`ORIGIN = 0x08003000`
- Flash 长度：`LENGTH = 256K - 12K`
- 同样删除 GCC10 不兼容的 `(READONLY)` 关键字

### 5.3 APP 入口添加向量表重映射
在 `main()` **最开始**添加：
```c
SCB->VTOR = 0x08003000;
```
防止 HAL 的 `SystemInit()` 将向量表改回 `0x08000000`。

### 5.4 添加 NMT 复位触发逻辑
在 CANopen 的 NMT 指令处理函数中，添加进入 Bootloader 的代码：

```c
#define BOOTLOADER_MAGIC_KEY  0xDEADBEEF

void EnterBootloader(void)
{
    volatile uint32_t *bootFlag = (volatile uint32_t *)0x2000FFF0;
    *bootFlag = BOOTLOADER_MAGIC_KEY;
    
    __DSB();           /* 确保写入完成 */
    __disable_irq();   /* 关闭中断 */
    NVIC_SystemReset();
}
```

**注意**：Bootloader 和 APP 的 `bootFlag` 地址必须完全一致。

### 5.5 生成 .srec 文件
BootCommander 只支持 `.srec`（Motorola S-record），不支持 Intel HEX。需要转换：

```bash
# 从 .hex 转换
objcopy -I ihex your_app.hex -O srec your_app.srec

# 或从 .elf 转换
arm-none-eabi-objcopy -O srec your_app.elf your_app.srec
```

## 6. 首次烧录方法

首次烧录时，Flash 里只有 Bootloader，APP 区域为空/无效，Bootloader 校验 checksum 失败后会自动停留。有两种方法烧入第一个 APP：

### 方法 A：利用 Bootloader 后门窗口（推荐）
Bootloader 上电后会打开 500ms 后门，只要在这 500ms 内上位机发送 XCP CONNECT，就会停留并允许升级。

如果手速不够，可临时将 `BOOT_BACKDOOR_ENTRY_TIMEOUT_MS` 改为 `5000`（5秒），烧完后再改回 500ms。

### 方法 B：J-Link 直接烧录 + 临时 bypass checksum（调试用）
在 `blt_conf.h` 中：
```c
#define BOOT_NVM_CHECKSUM_HOOKS_ENABLE  (1)
```

在 `hooks.c` 中：
```c
blt_bool NvmVerifyChecksumHook(void)
{
    return BLT_TRUE;
}
```

然后用 J-Link 把 APP 烧到 `0x08003000`。**生产环境必须关闭此 bypass**。

> **重要**：首次通过 BootCommander 刷写后，Bootloader 会自动在 `0x080031D8` 写入正确的 checksum，之后正常上电即可自动跳转。

## 7. 日常升级流程

```
1. 编译新 APP，生成 .srec 文件
        ↓
2. 通过 CAN 总线发送 NMT 复位指令到 APP
        ↓
3. APP 写 0xDEADBEEF 到 0x2000FFF0，执行 NVIC_SystemReset()
        ↓
4. Bootloader 启动，检测到 Magic Key，停留等待上位机
        ↓
5. PC 端执行 BootCommander 刷写命令：
   sudo ./BootCommander -t=xcp_can -d=can0 -b=500000 \
        -c=0x667 -m=0x7E1 your_app.srec
        ↓
6. Bootloader 接收 XCP 命令，擦除并写入 Flash
        ↓
7. 刷写完成，Bootloader 自动写入 checksum 并复位
        ↓
8. 跳转回新 APP 运行
```

## 8. 常见问题与解决

### Q1: 编译报错 `stm32g473xx.h: No such file or directory`
OpenBLT 自带的 CMSIS 包里只有 `stm32g474xx.h`。需要在同级目录下新建一个 wrapper：
```c
// stm32g473xx.h
#ifndef STM32G473xx_H
#define STM32G473xx_H
#include "stm32g474xx.h"
#endif
```

### Q2: 链接报错 `non constant or forward reference address expression for section .ARM.extab`
GCC 10 不支持链接脚本里的 `(READONLY)` 关键字。删除 `.ld` 文件里所有的 `(READONLY)` 即可。

### Q3: Bootloader 下载后 LED 不闪烁
- 检查 `led.c` 中的 GPIO 引脚是否与 `main.c` 初始化的一致
- 检查 PC15 是否被 LSE 占用，需加 `LL_RCC_LSE_Disable()`
- 检查 `SystemClock_Config()` 是否卡在某个 `while` 循环（PLL 没 ready）

### Q4: BootCommander 连接超时 `[TIMEOUT]`
- 检查 PC 端 `can0` 是否已启动：`sudo ip link set can0 up type can bitrate 500000`
- 检查 CAN 引脚和复用功能号（AF）是否正确
- **重点检查 FDCAN 实例号**：PB5/PB6 对应 **FDCAN2**，`blt_conf.h` 里 `BOOT_COM_CAN_CHANNEL_INDEX` 必须是 `1`
- 检查 CAN 总线终端电阻和共地

### Q5: 用 J-Link 烧录 APP 后，Bootloader 不跳转
J-Link 烧录不会自动写入 OpenBLT 的 checksum。必须通过 BootCommander 刷写一次，或临时开启 checksum bypass。

### Q6: NMT 复位后 Bootloader 不停留，直接跳 APP
- 检查 APP 里是否确实执行了 `*bootFlag = 0xDEADBEEF`
- 检查 APP 和 Bootloader 的 `bootFlag` 地址是否一致
- 用 J-Link 在 `NVIC_SystemReset()` 前查看 `0x2000FFF0` 是否为 `0xDEADBEEF`
- 建议把地址放到 RAM 末尾（如 `0x2001FFF0`）避免被启动代码覆盖
