# 电机模型

## 电压方程

永磁同步电机（PMSM）在旋转坐标系（d-q轴）下的电压方程为：

$$\begin{aligned}
u_d &= R_s i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q \\
u_q &= R_s i_q + L_q \frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \psi_f
\end{aligned}$$

其中：
- $u_d$, $u_q$：d轴和q轴电压
- $i_d$, $i_q$：d轴和q轴电流
- $R_s$：定子相电阻
- $L_d$, $L_q$：d轴和q轴电感
- $\omega_e$：电角速度（rad/s）
- $\psi_f$：永磁体磁链（Wb）

## 电压方程拉氏变化

对电压方程进行拉普拉斯变换，假设初始条件为零：

$$\begin{aligned}
U_d(s) &= R_s I_d(s) + s L_d I_d(s) - \omega_e L_q I_q(s) \\
U_q(s) &= R_s I_q(s) + s L_q I_q(s) + \omega_e L_d I_d(s) + \frac{\omega_e \psi_f}{s}
\end{aligned}$$


在控制系统分析中，通常忽略交叉耦合项（$\omega_e L_q i_q$ 和 $\omega_e L_d i_d$）和反电动势项（$\omega_e \psi_f$）进行简化，得到解耦的一阶系统：

$$\begin{aligned}
U_d(s) &= (R_s + s L_d) I_d(s) \\
U_q(s) &= (R_s + s L_q) I_q(s)
\end{aligned}$$

## 时间常数和带宽的关系推导

### 电机的时间常数

从简化的电压方程可得电的的传递函数：

$$\begin{aligned}
G_d(s) = \frac{I_d(s)}{U_d(s)} &= \frac{1}{R_s + s L_d} = \frac{1/R_s}{1 + s \frac{L_d}{R_s}} \\
G_q(s) = \frac{I_q(s)}{U_q(s)} &= \frac{1}{R_s + s L_q} = \frac{1/R_s}{1 + s \frac{L_q}{R_s}}
\end{aligned}$$

定义d轴和q轴的电气时间常数：

$$\begin{aligned}
\tau_d &= \frac{L_d}{R_s} \\
\tau_q &= \frac{L_q}{R_s}
\end{aligned}$$

则传递函数可表示为：

$$G_d(s) = \frac{K}{1 + s \tau_d}, \quad G_q(s) = \frac{K}{1 + s \tau_q}$$

其中 $K = 1/R_s$ 为增益。

### 电机的自然电气带宽（开环特性）

对于电机绕组本身，不考虑任何控制器时的被动响应特性：

**自然时间常数**：$$\tau = \frac{L}{R_s}$$

**自然带宽（角频率）**：$$\omega_{b,\text{natural}} = \frac{1}{\tau} = \frac{R_s}{L}$$

**自然带宽（频率）**：$$f_{b,\text{natural}} = \frac{\omega_{b,\text{natural}}}{2\pi} = \frac{R_s}{2\pi L}$$

#### 重要说明

这个 $f_{b,\text{natural}}$ 是**开环特性**，表示：
- 不加任何控制器时，电机绕组对电压阶跃的被动响应速度
- RL电路的自然截止频率
- 描述电机本身的电气惯性

**关键区别**：
- **开环自然带宽**：由电机物理参数 $R_s$ 和 $L$ 决定，通常较小（例如15-100Hz）

### 详细推导步骤（自然带宽）

#### 步骤1：频域分析

将 $s = j\omega$ 代入传递函数，得到频率响应：

$$G(j\omega) = \frac{K}{1 + j\omega \tau}$$

#### 步骤2：计算幅频特性

取频率响应的模（幅值）：

$$|G(j\omega)| = \left| \frac{K}{1 + j\omega \tau} \right| = \frac{K}{|1 + j\omega \tau|} = \frac{K}{\sqrt{1 + (\omega \tau)^2}}$$

#### 步骤3：直流增益

当 $\omega = 0$ 时（直流情况）：

$$|G(j0)| = \frac{K}{\sqrt{1 + 0}} = K$$

因此 $K$ 为系统的直流增益。

#### 步骤4：-3dB点定义

-3dB点表示幅值下降到直流增益的 $1/\sqrt{2}$ 倍，因为：

$$20 \log_{10}\left(\frac{1}{\sqrt{2}}\right) = 20 \log_{10}(2^{-1/2}) = -10 \log_{10}(2) \approx -3.01 \text{ dB}$$

所以带宽频率 $\omega_b$ 满足：

$$|G(j\omega_b)| = \frac{K}{\sqrt{2}}$$

#### 步骤5：建立方程

代入幅频特性表达式：

$$\frac{K}{\sqrt{1 + (\omega_b \tau)^2}} = \frac{K}{\sqrt{2}}$$

由于 $K > 0$，两边同时除以 $K$：

$$\frac{1}{\sqrt{1 + (\omega_b \tau)^2}} = \frac{1}{\sqrt{2}}$$

#### 步骤6：求解方程

两边取倒数：

$$\sqrt{1 + (\omega_b \tau)^2} = \sqrt{2}$$

两边平方：

$$1 + (\omega_b \tau)^2 = 2$$

移项：

$$(\omega_b \tau)^2 = 1$$

由于 $\omega_b > 0$，$\tau > 0$，取正平方根：

$$\omega_b \tau = 1$$

最终得到：

$$\omega_b = \frac{1}{\tau}$$

#### 步骤7：代入电机参数

将电机时间常数 $\tau = \frac{L}{R_s}$ 代入：

$$\omega_{b,\text{natural}} = \frac{1}{\tau} = \frac{R_s}{L}$$

#### 步骤8：转换为Hz单位

以Hz为单位的自然带宽：

$$f_{b,\text{natural}} = \frac{\omega_{b,\text{natural}}}{2\pi} = \frac{1}{2\pi \tau} = \frac{R_s}{2\pi L}$$

### 概念澄清与对比

#### 电机的自然电气特性（开环）

1. **时间常数 $\tau$**：电机绕组的电气惯性，$\tau = L/R_s$
   - 物理意义：电压阶跃下，电流达到稳态值63.2%所需时间
   - 设计约束：由电机物理结构决定，不易改变

2. **自然带宽 $f_{b,\text{natural}}$**：RL电路的截止频率，$f_{b,\text{natural}} = R_s/(2\pi L)$
   - 物理意义：不加控制器时，电机能响应的最高信号频率
   - 典型范围：10-100Hz（对于普通伺服电机）


#### 关键区别总结

| 特性 | 自然电气带宽（开环） | 电流环闭环带宽 |
|------|----------------------|----------------|
| **决定因素** | 电机参数 $R_s$、$L$ | 控制器参数 $K_p$、$K_i$ |
| **物理意义** | 绕组被动响应速度 | 系统跟踪指令能力 |
| **典型值** | 15-100 Hz | 500-2000 Hz |
| **设计约束** | 电机物理结构 | PWM频率、采样延迟 |
| **能否改变** | 基本固定 | 可通过软件调节 |

#### 实际设计指导

1. **电机选型**：
   - 自然带宽 $f_{b,\text{natural}}$ 描述电机电气惯性，但**不限制**闭环性能
   - 选择电机主要考虑转矩常数、反电动势、热特性等
   - $L/R_s$ 比值影响PI参数的 $K_i/K_p$ 设置，但不决定带宽上限

2. **控制器设计**：
   - 电流环带宽目标：$f_{b,\text{closed}} = 500\text{-}2000\text{Hz}$（典型）
   - 设计约束：$f_{b,\text{closed}} < \frac{1}{10} f_{\text{PWM}}$
   - PI参数设计：
     $$K_p = 2\pi f_{b,\text{closed}} L$$
     $$K_i = \frac{R_s}{L} K_p$$

3. **示例计算**：
   - 电机：$R_s=0.5\Omega$，$L=5\text{mH}$
   - 目标闭环带宽：$f_{b,\text{closed}}=1000\text{Hz}$
   - 计算PI参数：
     $$K_p = 2\pi \times 1000 \times 0.005 \approx 31.4$$
     $$K_i = \frac{0.5}{0.005} \times 31.4 \approx 3140$$
   - 验证：自然带宽 $f_{b,\text{natural}} \approx 15.9\text{Hz}$，闭环带宽 $1000\text{Hz}$，**提高63倍**

4. **系统限制**：
   - PWM频率：通常8-20kHz，限制最高闭环带宽
   - 采样延迟：1-2个PWM周期，影响相位裕度
   - 电压饱和：母线电压限制最大电流变化率
   - 数字量化：ADC分辨率、计算精度
