# 速度环控制器

## 速度环的数学模型

### 运动方程

对于永磁同步电机（PMSM）或直流电机，机械运动方程由牛顿第二定律描述：

$$J\frac{d\omega_m(t)}{dt} + B\omega_m(t) = T_e(t) - T_L(t)$$

其中：
- $\omega_m(t)$：机械角速度（rad/s）
- $J$：转动惯量（kg·m²）
- $B$：粘性摩擦系数（N·m·s/rad）
- $T_e(t)$：电磁转矩（N·m）
- $T_L(t)$：负载转矩（N·m）

### 转矩与电流关系

对于永磁同步电机，电磁转矩与q轴电流的关系为：

$$T_e(t) = \frac{3}{2}P\psi_f i_q(t) = K_t i_q(t)$$

其中：
- $P$：极对数
- $\psi_f$：永磁体磁链（Wb）
- $i_q(t)$：q轴电流（A）
- $K_t = \frac{3}{2}P\psi_f$：转矩常数（N·m/A）

## 速度环的拉普拉斯变换

### 运动方程的拉氏变换

对运动方程进行拉普拉斯变换（假设初始条件为零，忽略负载扰动 $T_L=0$）：

$$J[s\Omega_m(s)] + B\Omega_m(s) = T_e(s)$$

$$(Js + B)\Omega_m(s) = T_e(s)$$

### 速度环传递函数

结合转矩方程 $T_e(s) = K_t I_q(s)$，得到速度环的传递函数：

$$G_v(s) = \frac{\Omega_m(s)}{I_q(s)} = \frac{K_t}{Js + B}$$

写成标准一阶系统形式：

$$G_v(s) = \frac{K}{\tau s + 1}$$

其中：
- 增益：$K = \frac{K_t}{B}$
- 时间常数：$\tau = \frac{J}{B}$

### 考虑电流环的影响

实际系统中，速度环的内环是电流环。电流环通常设计为带宽较高的闭环系统，其闭环传递函数可近似为一阶惯性环节：

$$G_{i,closed}(s) \approx \frac{1}{1 + \tau_i s}$$

其中 $\tau_i = 1/\omega_{b,i}$ 为电流环时间常数，$\omega_{b,i}$ 为电流环带宽。通常 $\tau_i \ll \tau$（电流环带宽远高于速度环带宽）。

考虑电流环后，速度环的广义对象传递函数为：

$$G_{v,obj}(s) = G_{i,closed}(s) \cdot G_v(s) = \frac{K}{(\tau s + 1)(\tau_i s + 1)}$$

#### 工程近似分析

1. **低频近似**：在速度环截止频率 $\omega_{c,v} \ll 1/\tau_i$ 的频段内，电流环闭环可近似为增益为1，即 $G_{i,closed}(j\omega) \approx 1$，因此：
   $$G_{v,obj}(s) \approx \frac{K}{\tau s + 1} \quad (\text{低频近似})$$

2. **完整二阶模型**：如果考虑电流环动态，广义对象为二阶系统：
   $$G_{v,obj}(s) = \frac{K}{(\tau s + 1)(\tau_i s + 1)}$$
   此时速度环开环为三阶系统，PI控制器设计需采用对称最优法（Modulus Optimum）等高级设计方法。

#### 近似条件验证

速度环带宽 $\omega_{b,v}$ 与电流环带宽 $\omega_{b,i} = 1/\tau_i$ 的关系：
- 典型设计：$\omega_{b,v} = (0.1 \sim 0.2)\omega_{b,i}$
- 因此 $\omega_{b,v} \tau_i = (0.1 \sim 0.2) \ll 1$，低频近似成立

**结论**：在速度环带宽远低于电流环带宽的条件下，可合理使用一阶近似 $G_{v,obj}(s) \approx \frac{K}{\tau s + 1}$。

## PI控制器设计

### PI控制器传递函数

速度环通常采用PI控制器：

$$G_c(s) = K_{p,v} + \frac{K_{i,v}}{s} = K_{p,v}\left(1 + \frac{1}{T_{i,v}s}\right)$$

其中：
- $K_{p,v}$：速度环比例增益
- $K_{i,v}$：速度环积分增益
- $T_{i,v} = \frac{K_{p,v}}{K_{i,v}}$：积分时间常数

### 开环传递函数

速度环开环传递函数：

$$G_{open}(s) = G_c(s) \cdot G_{v,obj}(s) = \left(K_{p,v} + \frac{K_{i,v}}{s}\right) \cdot \frac{K}{\tau s + 1}$$

### 闭环传递函数

速度环闭环传递函数：

$$G_{closed}(s) = \frac{G_{open}(s)}{1 + G_{open}(s)} = \frac{K_{p,v}K s + K_{i,v}K}{\tau s^2 + (1 + K_{p,v}K)s + K_{i,v}K}$$

#### 闭环传递函数的零点分析

1. **带零点的二阶系统**：分子存在 $s$ 的一次项，表明系统有一个闭环零点：
   $$z = -\frac{K_{i,v}}{K_{p,v}} = -\frac{1}{T_{i,v}}$$
   其中 $T_{i,v} = K_{p,v}/K_{i,v}$ 为积分时间常数。

2. **标准形式表示**：将闭环传递函数化为标准二阶系统加零点的形式：
   $$G_{closed}(s) = \frac{\frac{K_{p,v}K}{\tau}\left(s + \frac{1}{T_{i,v}}\right)}{s^2 + \frac{1+K_{p,v}K}{\tau}s + \frac{K_{i,v}K}{\tau}}$$

   定义：
   - 自然频率：$\omega_n = \sqrt{\frac{K_{i,v}K}{\tau}}$
   - 阻尼比：$\zeta = \frac{1 + K_{p,v}K}{2\sqrt{\tau K_{i,v}K}}$
   - 零点位置：$z = -1/T_{i,v}$

3. **零点对动态响应的影响**：
   - 闭环零点 $z = -1/T_{i,v}$ 会**增大阶跃响应的超调量**
   - 即使按照标准二阶系统设计 $\zeta = 0.7$，实际超调量也会**大于**无零点系统的4.6%
   - 零点使系统响应更"冲"，上升时间缩短但超调增加
   - 零点的影响程度取决于 $|z|/\omega_n$ 的比值：比值越大，影响越小

4. **设计考虑**：
   - 若按标准二阶公式设计PI参数，实际响应会比预期更"冲"
   - 需要适当**减小比例增益 $K_{p,v}$** 或**增大积分时间 $T_{i,v}$** 来补偿零点影响
   - 实际设计时，目标阻尼比应略高于无零点系统的设计值

#### 负载扰动传递函数

对于伺服系统，抗负载扰动能力往往是速度环设计的核心指标之一。需要考虑负载转矩 $T_L$ 对速度的影响。

**完整系统方程**（考虑负载扰动）：

$$J\frac{d\omega_m}{dt} + B\omega_m = T_e - T_L$$
$$T_e = K_t i_q$$
$$i_q = G_c(s)(\omega_{ref} - \omega_m)$$

**扰动传递函数**（从负载转矩 $T_L$ 到速度 $\omega_m$）：

设 $\omega_{ref} = 0$，分析负载扰动的影响：

$$(Js + B)\Omega_m(s) = K_t I_q(s) - T_L(s)$$
$$I_q(s) = -G_c(s)\Omega_m(s)$$

代入得：
$$(Js + B)\Omega_m(s) = -K_t G_c(s)\Omega_m(s) - T_L(s)$$

整理：
$$[Js + B + K_t G_c(s)]\Omega_m(s) = -T_L(s)$$

因此负载扰动传递函数为：

$$G_{d}(s) = \frac{\Omega_m(s)}{T_L(s)} = \frac{-1}{Js + B + K_t G_c(s)}$$

代入PI控制器 $G_c(s) = K_{p,v} + \frac{K_{i,v}}{s}$：

$$G_{d}(s) = \frac{-1}{Js + B + K_t\left(K_{p,v} + \frac{K_{i,v}}{s}\right)} = \frac{-s}{Js^2 + (B + K_t K_{p,v})s + K_t K_{i,v}}$$

**标准化形式**：

$$G_{d}(s) = -\frac{s/J}{s^2 + \frac{B + K_t K_{p,v}}{J}s + \frac{K_t K_{i,v}}{J}}$$

**扰动抑制特性**：
1. **稳态扰动抑制**：
   - 对于恒定负载扰动（$T_L = \text{const}$），即 $s \to 0$ 时：
     $$\lim_{s\to 0} G_{d}(s) = 0$$
   - 表明PI控制器能**完全抑制**恒定负载扰动，实现速度零稳态误差

2. **频域特性分析**：
   - 扰动传递函数：$G_{d}(s) = -\frac{s/J}{s^2 + \frac{B + K_t K_{p,v}}{J}s + \frac{K_t K_{i,v}}{J}}$
   
   - **低频段**（$\omega \to 0$）：
     $$|G_{d}(j\omega)| = \left|\frac{-j\omega/J}{-\omega^2 + j\omega\frac{B+K_t K_{p,v}}{J} + \frac{K_t K_{i,v}}{J}}\right| \approx \frac{\omega/J}{K_t K_{i,v}/J} = \frac{\omega}{K_t K_{i,v}} \to 0$$
     完全抑制恒定扰动，稳态误差为零。
   
   - **高频段**（$\omega \gg \omega_n$）：
     令 $s = j\omega$，当 $\omega \to \infty$ 时，分母中 $s^2$ 项主导：
     $$G_{d}(j\omega) \approx \frac{-j\omega/J}{-\omega^2} = \frac{j}{J\omega}$$
     $$|G_{d}(j\omega)| \approx \frac{1}{J\omega} \to 0$$
     衰减斜率 -20dB/dec，高频扰动被转动惯量 $J$ 自然滤波抑制。
   
   - **中频段**（$\omega \approx \omega_n = \sqrt{\frac{K_t K_{i,v}}{J}}$）：
     可能存在谐振峰，抑制能力相对最弱，是扰动抑制的关键频段。

3. **动态扰动抑制能力**：
   - **零点在原点** $s=0$：保证对恒定扰动的完全抑制
   - **高频衰减**：转动惯量 $J$ 提供自然滤波，高频扰动被有效抑制
   - **最弱抑制频段**：在接近速度环带宽 $\omega_n$ 的频率范围内，扰动抑制能力相对较弱
   - 系统对**缓变扰动**抑制能力强，对**中频段扰动**抑制能力相对较弱，对**高频扰动**由于惯量作用再次被抑制

4. **设计指导**：
   - 扰动抑制带宽：$\omega_n = \sqrt{\frac{K_t K_{i,v}}{J}}$
   - 应使 $\omega_n$ 覆盖预期的负载扰动主要频率成分
   - 增大 $K_{i,v}$ 可提高扰动抑制带宽，但需考虑稳定性
   - 转动惯量 $J$ 越大，高频扰动抑制效果越好，但动态响应变慢
