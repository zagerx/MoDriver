# 控制器设计

## PI控制器的数学公式

### 1. 时域方程

连续时间PI控制器的输出 $u(t)$ 与误差 $e(t)$ 的关系：

$$u(t) = K_p e(t) + K_i \int_0^t e(\tau) d\tau$$

其中：
- $K_p$：比例增益
- $K_i$：积分增益
- $e(t) = r(t) - y(t)$：参考值 $r(t)$ 与测量值 $y(t)$ 的误差

### 2. 拉普拉斯变换与传递函数

对时域方程进行拉普拉斯变换（假设初始条件为零）：

$$U(s) = K_p E(s) + K_i \frac{E(s)}{s}$$

传递函数为：

$$G_c(s) = \frac{U(s)}{E(s)} = K_p + \frac{K_i}{s}$$

#### 常用等价形式

1. **时间常数形式**：
   $$G_c(s) = K_p \left(1 + \frac{1}{T_i s}\right)$$
   其中积分时间常数 $T_i = K_p / K_i$。

2. **零极点形式**：
   $$G_c(s) = K_p \frac{T_i s + 1}{T_i s}$$
   零点：$s = -1/T_i$，极点：$s = 0$。

### 3. 闭环系统分析

#### 电流环闭环传递函数

假设电机传递函数为 $G_m(s) = \frac{1/R_s}{1 + s\tau}$，其中 $\tau = L/R_s$：

开环传递函数：

$$G_{\text{open}}(s) = G_c(s) G_m(s) = \left(K_p + \frac{K_i}{s}\right) \frac{1/R_s}{1 + s\tau}$$

闭环传递函数：

$$G_{\text{closed}}(s) = \frac{G_{\text{open}}(s)}{1 + G_{\text{open}}(s)} = \frac{K_p s + K_i}{\tau R_s s^2 + (R_s + K_p) s + K_i}$$

#### 零极点对消设计

当 $K_i/K_p = 1/\tau = R_s/L$ 时，可实现零极点对消。此时 $K_i = K_p \frac{R_s}{L}$，代入开环传递函数：

$$G_{\text{open}}(s) = \left(K_p + K_p\frac{R_s}{L}\frac{1}{s}\right) \frac{1/R_s}{1 + s\frac{L}{R_s}} = \frac{K_p(s + \frac{R_s}{L})}{s} \cdot \frac{1/R_s}{1 + s\frac{L}{R_s}}$$

注意：$1 + s\frac{L}{R_s} = \frac{R_s + sL}{R_s} = \frac{L(s + \frac{R_s}{L})}{R_s}$

因此：
$$G_{\text{open}}(s) = \frac{K_p(s + \frac{R_s}{L})}{s} \cdot \frac{1/R_s}{\frac{L(s + \frac{R_s}{L})}{R_s}} = \frac{K_p(s + \frac{R_s}{L})}{s} \cdot \frac{1}{L(s + \frac{R_s}{L})} = \frac{K_p}{L s}$$

零极点对消后，开环传递函数简化为积分器：

$$G_{\text{open}}(s) = \frac{K_p}{L s}$$

#### 闭环系统简化

闭环传递函数：

$$G_{\text{closed}}(s) = \frac{G_{\text{open}}(s)}{1 + G_{\text{open}}(s)} = \frac{\frac{K_p}{L s}}{1 + \frac{K_p}{L s}} = \frac{1}{1 + \frac{L}{K_p} s}$$

#### 正确闭环带宽公式

闭环时间常数：

$$\tau_{\text{closed}} = \frac{L}{K_p}$$

闭环带宽（角频率）：

$$\omega_{b,\text{closed}} = \frac{1}{\tau_{\text{closed}}} = \frac{K_p}{L}$$

闭环带宽（频率）：

$$f_{b,\text{closed}} = \frac{\omega_{b,\text{closed}}}{2\pi} = \frac{K_p}{2\pi L}$$

#### 量纲验证

- $K_p$ 单位：V/A（电压/电流）
- $L$ 单位：H = V·s/A（亨利）
- $\frac{K_p}{L}$ 单位：$\frac{\text{V/A}}{\text{V·s/A}} = \frac{1}{\text{s}}$，正确！
- $f_{b,\text{closed}} = \frac{K_p}{2\pi L}$ 单位：Hz，正确！

#### 与设计公式的一致性验证

从设计公式 $K_p = 2\pi f_{b,\text{closed}} L$ 代入带宽公式：

$$f_{b,\text{closed}} = \frac{K_p}{2\pi L} = \frac{2\pi f_{b,\text{closed}} L}{2\pi L} = f_{b,\text{closed}}$$
