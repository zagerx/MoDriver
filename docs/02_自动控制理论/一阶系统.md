# 一阶系统

## 典型的一阶微分方程

一阶系统的典型微分方程为：

$$\tau \frac{dy(t)}{dt} + y(t) = K u(t)$$

其中：
- $y(t)$：系统输出
- $u(t)$：系统输入
- $\tau$：时间常数（Time Constant），单位为秒（s）
- $K$：系统增益（Gain），无量纲或具有相应的物理单位

### 物理意义
- 时间常数 $\tau$：表示系统响应速度，$\tau$ 越小系统响应越快
- 增益 $K$：表示系统对输入信号的放大倍数

## 拉氏变换

对微分方程两边进行拉普拉斯变换，假设初始条件 $y(0) = 0$：

$$\tau [s Y(s) - y(0)] + Y(s) = K U(s)$$

代入 $y(0) = 0$ 得：

$$\tau s Y(s) + Y(s) = K U(s)$$

整理得到传递函数：

$$G(s) = \frac{Y(s)}{U(s)} = \frac{K}{\tau s + 1}$$

### 标准形式

一阶系统的标准传递函数形式为：

$$G(s) = \frac{K}{T s + 1}$$

其中 $T = \tau$ 为时间常数。

### 极点和零点

- 极点：$s = -\frac{1}{\tau}$
- 无有限零点
- 系统稳定的充要条件：$\tau > 0$（极点在左半平面）

## 拉普拉斯逆变换解出微分方程

### 阶跃响应

当输入为单位阶跃信号 $u(t) = 1(t)$，即 $U(s) = \frac{1}{s}$ 时：

$$Y(s) = G(s) U(s) = \frac{K}{\tau s + 1} \cdot \frac{1}{s}$$

进行部分分式分解：

$$Y(s) = K \left( \frac{1}{s} - \frac{1}{s + \frac{1}{\tau}} \right)$$

对每一项进行拉普拉斯逆变换：

$$y(t) = K \left( 1 - e^{-\frac{t}{\tau}} \right), \quad t \geq 0$$

### 阶跃响应特性

1. **初始值**：$y(0) = 0$
2. **稳态值**：$y(\infty) = K$
3. **时间常数处的值**：$y(\tau) = K (1 - e^{-1}) \approx 0.632K$
   - 即经过一个时间常数 $\tau$，响应达到稳态值的63.2%
4. **上升时间**（10%到90%）：$t_r \approx 2.2\tau$
5. **调节时间**（达到稳态值的±5%）：$t_s \approx 3\tau$
6. **调节时间**（达到稳态值的±2%）：$t_s \approx 4\tau$

### 脉冲响应

当输入为单位脉冲信号 $u(t) = \delta(t)$，即 $U(s) = 1$ 时：

$$Y(s) = G(s) = \frac{K}{\tau s + 1}$$

拉普拉斯逆变换：

$$y(t) = \frac{K}{\tau} e^{-\frac{t}{\tau}}, \quad t \geq 0$$

### 频率响应

令 $s = j\omega$，代入传递函数：

$$G(j\omega) = \frac{K}{1 + j\omega\tau}$$

1. **幅频特性**：

   $$|G(j\omega)| = \frac{K}{\sqrt{1 + (\omega\tau)^2}}$$

2. **相频特性**：

   $$\angle G(j\omega) = -\arctan(\omega\tau)$$

3. **带宽**：
   - 截止频率（-3dB点）：$\omega_b = \frac{1}{\tau}$
   - 带宽：$f_b = \frac{1}{2\pi\tau}$

### 一般输入响应

对于任意输入 $u(t)$，可通过卷积积分求解：

$$y(t) = \int_0^t g(t-\tau) u(\tau) d\tau$$

其中 $g(t) = \frac{K}{\tau} e^{-\frac{t}{\tau}}$ 为系统的脉冲响应。

### 数值示例

考虑一阶系统：$\tau = 0.1\, \text{s}$，$K = 2$

1. **传递函数**：$G(s) = \frac{2}{0.1s + 1} = \frac{20}{s + 10}$

2. **阶跃响应**：$y(t) = 2(1 - e^{-10t})$

3. **时间常数**：$\tau = 0.1\, \text{s}$

4. **0.1秒时的响应**：$y(0.1) = 2(1 - e^{-1}) \approx 1.264$

5. **带宽**：$\omega_b = \frac{1}{0.1} = 10\, \text{rad/s}$，$f_b = \frac{10}{2\pi} \approx 1.59\, \text{Hz}$

### 总结公式

| 参数 | 符号 | 公式 |
|------|------|------|
| 微分方程 | | $\tau \frac{dy}{dt} + y = K u$ |
| 传递函数 | $G(s)$ | $\frac{K}{\tau s + 1}$ |
| 极点 | $s_p$ | $-\frac{1}{\tau}$ |
| 阶跃响应 | $y(t)$ | $K(1 - e^{-t/\tau})$ |
| 脉冲响应 | $g(t)$ | $\frac{K}{\tau} e^{-t/\tau}$ |
| 时间常数 | $\tau$ | 达到稳态值63.2%的时间 |
